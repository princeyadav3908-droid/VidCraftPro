# VidCraft Pro — Android starter project

This is the first native Android project foundation for VidCraft Pro.

## Included in this starter
- Kotlin + Jetpack Compose dark UI
- Home dashboard for Video Editor, Background Studio, Color Lab, Selective Blur, Audio Studio and Color Grading
- Android system video picker
- In-app video preview using Android Media3 ExoPlayer
- Tool screens with initial control layouts

## Important
This is **not yet a finished editing app**. The controls in this first foundation are UI prototypes. Color removal, AI background removal, motion tracking, blur rendering, audio effects and export processing still need to be implemented and tested as subsequent modules.

## Open in Android Studio
1. Install Android Studio on a computer.
2. Extract this ZIP.
3. In Android Studio choose **Open**, then select the `VidCraftPro` folder.
4. Allow Gradle sync to finish.
5. Run on an Android phone with USB debugging enabled or an emulator.

A compatible Android SDK and internet access are needed for the first Gradle sync.
